# LegecloPlayer

某寢室再生用

## 動作要件

- Windows 10 (1607)以降のWindows OS
- Microsoft Visual C++ v14 (x64)

## 再生方法

次のような階層構造から成る素材・脚本を用意した上で、メニュー欄`File->Open`から`cs_*02.evsc`もしくは`cs_*03evsc`ファイルを選択して下さい。

<pre>
gamedata
├ adv
│ ├ movie // 動画フォルダ
│ │  ├ hs_aera_mo_0201.mp4
│ │  ├ hs_aera_mo_0202.mp4
│ │  ├ hs_aera_mo_0203.mp4
│ │  └ ...
│ ├ scenario // 脚本フォルダ
│ │  ├ ...
│ │  ├ cs_aera_02.evsc // この形式のファイルを選択
│ │  ├ cs_aera_03.evsc
│ │  └ ...
│ └ still // 静画フォルダ
│    ├ hs_aera_st_0201.png
│    ├ hs_aera_st_0202.png
│    ├ hs_aera_st_0301.png
│    └ ...
└ sound
  └ webgl
     └ adv // 音声フォルダ
        ├ ...
        ├ cs_aera_02
        │  ├ voice_s2_aera_0001_01.wav
        │  ├ voice_s2_aera_0002_01.wav
        │  └ ...
        ├ cs_aera_03
        └ ...
</pre>

## メニュー機能

| 分類 | 項目 | 機能 |
| --- | --- | --- |
| File | Open | 脚本ファイル選択ダイアログ表示。 |
| - | Next | 次の脚本を開く。 |
| - | Previous | 前の脚本を開く。 |
| Setting | Audio | 音声設定ダイアログ表示。 |
| - | Video | 動画設定ダイアログ表示。 |
| - | Font | 字体設定ダイアログ表示。 |
| Image | Pause | 動画を一時停止・再開。 |
| Image | Sync | 画像と文章を同期 / 独立して制御。 |

- 一時停止中は左クリックで1コマずつ進めることができます。
- 同期を切っている間は、左クリックで次の画像・動画に切り替わります。

## マウス機能

| 入力 | 機能 |
| --- | --- |
| ホイール回転 | 拡大・縮小。 |
| 左ドラッグ | 表示範囲移動。モニタ解像度以上に拡大した場合のみ動作。 |
| 中クリック | 原寸大表示。 |
| 右クリック | 場面遷移メニュー表示。 |
| 右押し + ホイール回転 | 文章送り・戻し。 |
| 右押し + 中クリック | 窓枠消去・表示。消去時にはモニタ原点位置に移動。 |
| 右押し + 左クリック | 窓移動。 窓枠消去時のみ動作。|

- 脚本が読み込まれている場合のみ有効です。
- 場面遷移メニューからは静画・画像が切り替わる場面に飛ぶことができます。

## キーボード機能

| 入力 | 機能 |
| --- | --- |
| <kbd>Esc</kbd> | 終了。 |
| <kbd>C</kbd> | 文字色黒・白切り替え。 |
| <kbd>T</kbd> | 文章表示・非表示切り替え。 |
| <kbd>∧</kbd> | 前の脚本を開く。 |
| <kbd>∨</kbd> | 次の脚本を開く。 |
| <kbd>＞</kbd> | 文章送り。 |
| <kbd>＜</kbd> | 文章戻し。 |
